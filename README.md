# fall-site
A simple fall themed website

It's autumn. It's chilly. We get so many fun Halloween and Christmas themed things. But have you ever been on a fall themed website?

This was meant to be a fun, highly interactive website. Due to time restraints and external commitments, it is very unfinished. 

Features:
 - Main Page: Just a short little message introducing the site.
 - Puzzles: You can play a crossword puzzle that I put my blood, sweat, and tears into. There would (should I have the time to continue this project) be more kinds of puzzles.
 - Games: Unfortunately, I wasn't able to get my game up and running. Hopefully I will soon, but it will have been after the Pixl deadline. But the intention was to have a flappy clone and other fall-themed games. They are still coming, just extremely delayed.
