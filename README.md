# fall-site
A simple fall themed website

It's autumn. It's chilly. We get so many fun Halloween and Christmas themed things. But have you ever been on a fall themed website?

This was meant to be a fun, highly interactive website. Due to time restraints and external commitments, it is very unfinished.
